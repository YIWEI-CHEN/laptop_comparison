# Windows Laptop Recommendations for Senior Applied Scientists

## Requirements Summary
- **OS**: Windows (x86-64 architecture, no ARM or ChromeBooks)
- **Memory**: Minimum 64GB RAM
- **Storage**: Minimum 1TB SSD

  - 4+ VS Code projects simultaneously
  - 50+ browser tabs in Edge
  - 50+ browser tabs in Chrome

## Key Considerations for Your Workload

### 1. **Memory (RAM) - Critical**
- **64GB is the minimum** you specified, and it's perfect for:
  - Running 4+ VS Code projects with Language Servers
  - 100+ browser tabs (50 Edge + 50 Chrome)
  - Multiple AI assistants (Claude Desktop, ChatGPT Desktop)
  - M365 Copilot and Office Suite
  - Docker containers for development
  - Background services

- **Consider 96GB or 128GB** if:
  - You frequently work with large datasets locally
  - You run local ML model inference
  - You use virtual machines alongside development

### 2. **CPU - Intel Core Ultra 7/9 or i9-13th Gen**
- **16-core CPUs** (Intel Core Ultra 7 155H/Ultra 9 185H): 
  - Excellent for multitasking
  - Efficient performance cores + performance cores architecture
  - Lower power consumption = better battery life
  
- **24-core CPUs** (Intel i9-13980HX):
  - Maximum performance for compilation and local testing
  - Best for parallel workloads
  - Higher power consumption

### 3. **GPU Considerations**
Since you train models in Azure (not locally), GPU is "nice to have":

- **NVIDIA RTX 2000/3000 Ada (Workstation)**:
  - Professional drivers and certifications
  - 8-12GB VRAM sufficient for testing models
  - Excellent CUDA support
  - Better for professional applications

- **NVIDIA RTX 4060/4070 (Consumer)**:
  - More gaming-focused but excellent for ML
  - Better price-to-performance
  - 8GB VRAM adequate for most local testing
  - Great for occasional local training

**Recommendation**: Since you primarily train in Azure, the workstation GPUs (RTX 2000/3000 Ada) are ideal - they provide enough power for local testing and prototyping while being optimized for professional workflows.

### 4. **Storage - NVMe SSD**
- **1TB minimum** (as specified) is good for:
  - OS, applications, and tools
  - Multiple project repositories
  - Some datasets and model checkpoints
  
- **2TB recommended** for:
  - More breathing room for datasets
  - Docker images and containers
  - VM images
  - Cache for AI tools

- All recommended laptops use **PCIe Gen 4 NVMe SSDs** with read speeds of 7000+ MB/s - extremely fast for your use case.

### 5. **Display**
For development and data work:
- **16" is optimal** - good balance of screen real estate and portability
- **1920x1200 (WUXGA)**: Great for coding, better battery life
- **2560x1600 or higher**: More screen space for multiple windows
- **4K/OLED**: Beautiful but impacts battery life
